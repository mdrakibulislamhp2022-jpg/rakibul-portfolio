# Rakibul Islam - Portfolio

A responsive personal portfolio made with HTML, CSS and vanilla JavaScript.

## Run locally
Open index.html in your browser, or use the VS Code Live Server extension.

## Before publishing
1. Replace YOUR_EMAIL@example.com in index.html with your real email.
2. Replace the placeholder GitHub links with your actual repository and profile links.
3. Verify the project descriptions and technologies match your real work.
4. Only claim skills and experience you actually have.

No build step or npm install is required.
